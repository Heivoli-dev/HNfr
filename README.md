# Heivoli Network

Site vitrine de la communauté Discord Heivoli Network, inspirée d'une interface bleue et minimaliste.

## Publication

Le site est statique et peut être publié avec GitHub Pages. Une fois GitHub Pages activé, choisissez la branche `main` et le dossier racine (`/`).

## À configurer plus tard

- Dans `app.js`, ajoutez le lien d'invitation Discord dans `discordInvite` pour activer le bouton « Rejoindre le Discord ».
- La connexion Discord/Google est volontairement préparée visuellement seulement. Une authentification réelle nécessite une application OAuth, un serveur sécurisé et une base de données ; elle sera ajoutée avec le futur bot.
